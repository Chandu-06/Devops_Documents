 QUICK REFERENCE: MOST USED COMMANDS
----------------------------------------------------------------

  terraform init              # Download providers + initialize
  terraform validate          # Check for syntax errors
  terraform fmt               # Format code
  terraform plan              # Preview changes (ALWAYS do this first)
  terraform apply             # Create/update infrastructure
  terraform destroy           # Delete everything
  terraform output            # Show outputs
  terraform state list        # List tracked resources
  terraform workspace select  # Switch environment

----------------------------------------------------------------
 QUICK REFERENCE: KEY FILES
----------------------------------------------------------------

  main.tf              → Resources and module calls
  variables.tf         → Variable declarations
  outputs.tf           → Output declarations
  providers.tf         → Provider + Terraform settings
  locals.tf            → Local computed values
  terraform.tfvars     → Default variable values
  .gitignore           → Must exclude terraform.tfstate
  .terraform.lock.hcl  → Commit this! Locks provider versions

----------------------------------------------------------------
 REMEMBER: THE GOLDEN RULES
----------------------------------------------------------------

  1. NEVER manually edit terraform.tfstate
  2. NEVER commit terraform.tfstate to Git
  3. NEVER hardcode secrets in .tf files
  4. ALWAYS run terraform plan before terraform apply
  5. ALWAYS use remote state in team environments
  6. ALWAYS pin provider and module versions
  7. ALWAYS tag all resources
